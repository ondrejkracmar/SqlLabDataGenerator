# Disconnect-SldgDatabase

## SYNOPSIS

Disconnects from the active database connection.

## SYNTAX

### __AllParameterSets

```

```

## DESCRIPTION

Closes the active connection established by Connect-SldgDatabase and releases the
PSSqlRepository session behind it.

## EXAMPLES
